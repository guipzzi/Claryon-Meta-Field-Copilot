## Assistência de ferramenta

Parte dos commits traz também `Co-Authored-By: Claude`, referente ao uso de
Claude Code como ferramenta de desenvolvimento. Isso é registro de proveniência,
não atribuição de autoria: as decisões de produto, de arquitetura e de aceite são
dos coautores humanos acima, e estão documentadas commit a commit em
[`DECISIONS.md`](DECISIONS.md).

## Créditos de terceiros

O projeto embarca software de terceiros sob suas próprias licenças — entre eles
whisper.cpp, llama.cpp, sherpa-onnx, Piper/VITS, Silero VAD, MapLibre, ML Kit e o
Meta Wearables Device Access Toolkit. O modelo de linguagem embarcado é o
**Qwen2.5-1.5B-Instruct** (Apache-2.0). Nenhum deles é de autoria da equipe.
